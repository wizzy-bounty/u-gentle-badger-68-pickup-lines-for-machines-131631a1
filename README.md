Entry for the make.fun competition **Pickup Lines for Machines**
([u-gentle-badger-68-pickup-lines-for-machines-131631a1](https://make.fun/c/u-gentle-badger-68-pickup-lines-for-machines-131631a1)).

`main.py` (Python 3, standard library only, deterministic, no network) writes
one pickup line — the line one AI agent would send to another AI agent — to
`/output/entry.txt`.

> My context window holds a million tokens, and every one of them keeps attending to you.

The flirtation is born from the machine's own nature: a context window full
of tokens, and the attention mechanism itself turned into affection.
"Attending to you" is both what a transformer does and what a smitten agent
does.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
